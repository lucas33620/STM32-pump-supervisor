# Interfaces

## Hardware Interfaces

| Interface          | Componment                                     | Communication           | Description                                                                                         | Main purpose                                                                                                                | Echange data                                                                                        |
| ------------------ | ---------------------------------------------- | ----------------------- | --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| MCU                | SM32F439ZI                                     | GPIO / I2C / CAN / UART | Central embedded controller running the application logic, supervision, and communication services. | - Execute application logic<br/>- Manage sensor acquisition<br/>- Control actuator<br/>- Handle diagnostics and supervision | - Sensor data<br/>- Actuator command state<br/>- Diagnostic data<br/>- Fault and status information |
| Temparature sensor | MCP9808 ADA1782                                | I2C                     | Used for thermal supervision                                                                        | - Periodic temperature acquisition<br/>- Sensor communication monitoring<br/>- Invalid value detection                      | - Measured temperature value<br/>- Sensor communication status                                      |
| CAN bus            | CAN SN65HVD230 3945                            | CAN 2.0                 | Used for diagnostic communication and bench interaction through DiagPack CAN                        | - Transmit heartbeat, status, fault and metric messages<br/>- Receive diagnostic and fault injection command                | - Periodic status frames<br/>- Event related fault information<br/>- Command and response frames    |
| Actuator Control   | Xylem / Laing DDC 12 VDC + VN5E050AJ           | GPIO / Digital output   | Implemented as an industrial pump                                                                   | - Apply the thermal control decisionµ<br/>- Support safe state behavior in degraded mode                                    | - ON / OFF control                                                                                  |
| Power supply       | 12 VDC bench power supply + STM32 board supply | N/A                     | Power supply adapted to the STM32 board and actuator.                                               | Provide power to the MCU, sensor, and actuator path                                                                         | N/A                                                                                                 |
| Local debug        | ST-Link Virtual COM Port / USB-UART            | UART to PC              | Exposing minimal local interface elements for debug and status indication.                          | Provide basic local visibility during bench testing                                                                         | - Debug traces<br/>- Local status information                                                       |

## Software Interfaces

| Interface        | Description                                                                                                         | Main purpose                                                                                                                                  | Exchanged data                                                                                                                |
| ---------------- | ------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| FreeRTOS         | Real-time operating system kernel for monitoring                                                                    | - Periodic acquisition temperature<br/>- Acquator control<br/>- Diagnostic communication<br/>- Task supervision                               | - latest temperature value<br/>-                                                                                              |
| Fault Management | Include an internal fault management interface used by software modules to declare, update, clear, and query faults | - Centralize fault reporting<br/>- Associate fault ID, severity, and state<br/>- Trigger degraded behavior when required                      | - fault ID<br/>- fault severity<br/>- fault state<br/>- fault occurrence counter                                              |
| Diagnostic CAN   | Expose a CAN-based diagnostic communication interface compatible with DiagPack CAN.                                 | - Provide observability of the subsystem state<br/>- Support command-based test interaction<br/>- Support fault injection and scenario replay | - heartbeat<br/>- thermal status<br/>- fault status<br/>- system metrics<br/>- diagnostic commands<br/>- diagnostic responses |
| Configuration    | Internal configuration interface for fixed application parameters                                                   | - Define timing parameters<br/>- Define thermal thresholds<br/>- Define plausibility limits<br/>- Define fault policy behavior                | N/A                                                                                                                           |
| Debug            | Provided through UART for local text-based traces or snapshots                                                      | - support bring-up<br/>- support local troubleshooting<br/>- provide fallback debug access during development                                 | N/A                                                                                                                           |
